### 2-4 可变参数

```python
def func(*args,**kwargs):
	print(args)  # args： 接收位置参数，返回元祖
	print(kwargs)# kwargs : 接收关键词参数，返回字典
	
func(10,20,30) #位置传参
func(a=10,b=20,c=30,d=40) #关键词传参
```

## 4- 匿名函数 lambda

```python
#普通函数
def func(num1,num2):
	return num1 ** num2
	
print(func(2,3))


# lambda表达式
func2 = lambda num1,num2 : num1 ** num2
print(func2(2,3))
```
