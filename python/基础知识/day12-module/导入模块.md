```python


import my_module  # 导入整个模块，使用是需要加上模块名 my_module.
import my_module as my_md  # 导入整个模块并重命名，使用是需要加上模块名 my_md.
from my_module import add,author # 导入指定的函数或者变量 ，使用时不需要加模块名
from my_module import add as my_add # 导入指定的函数或者变量并重命名 ，使用时不需要加模块名，直接使用重命名后的名称
from my_module import * # 导入模块中的所有函数和变量，使用时不需要加模块名


```

# 1- import my_module   

- 导入整个模块，使用是需要加上模块名 my_module.

# 2- import my_module as my_md  

- 导入整个模块并重命名，使用是需要加上模块名 my_md.



# 3- from my_module import add,author  

- 导入指定的函数或者变量 ，使用时不需要加模块名



# 4- from my_module import add as my_add 

- 导入指定的函数或者变量并重命名 ，使用时不需要加模块名，直接使用重命名后的名称



# 5- from my_module import * 

- 导入模块中的所有函数和变量，使用时不需要加模块名
